### F3 — Low — `src/secrets.rs:92-99`, `src/capture.rs:129-135` — create-then-chmod
- `fs::write`/`File::create` creates with umask mode (typically 0644) and then `set_permissions(0o600)`. On first creation there is a window where `secrets.json` is world-readable; `RecFile::create`'s comment claims "permission is in place before any audio is written" — true for audio, but the file itself is briefly 0644.
- Fix (unix): `OpenOptions::new().write(true).create(true).truncate(true).mode(0o600).open(&path)` under `#[cfg(unix)]`, plain `File::create` otherwise. Removes the race and the follow-up chmod.
